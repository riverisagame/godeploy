     ```go
     type Pipeline struct {
         Version string
         Stages  []string
         Tasks   map[string]*TaskConfig

     type TaskConfig struct {
         Stage  string
         Type   string   // "script" or "sync"
         RunOn  string   // "local" or "remote"
         Script []string
     }
     ```

## 阶段2：流水线执行器 (Pipeline Runner)
**目标**：把原本冗长且硬编码在 `DeployEngine` 的执行逻辑抽离。
1. **[NEW] `internal/application/pipeline_runner.go`**:
   - 定义 `PipelineRunner` 结构体，依赖 `DeployEngine` 注入的 `sshClient`, `serverSvc`, 及广播 `logChan`。
   - `Run(ctx context.Context, p *domain.Pipeline, workspacePath, releaseName string, env *domain.Environment, deployID uint, logger func(string))`。
   - `Run` 方法按照 `p.Stages` 的顺序遍历 `p.Tasks` 并执行。
     - 若 `Type == "sync"`，调用 `sshClient.SyncFiles`。
     - 若 `Type == "script"` 且 `RunOn == "local"`，使用 `exec.Command` 在 `workspacePath` 运行。
     - 若 `Type == "script"` 且 `RunOn == "remote"`，使用 `sshClient.RunCommand` 在远端运行。
2. **[NEW] `internal/application/pipeline_runner_test.go`**:
   - Mock SSH 和 ServerSvc 测试 PipelineRunner 的顺次执行和容错中断。
