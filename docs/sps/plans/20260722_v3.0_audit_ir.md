# [TASK-5] 审计日志 (Audit Log) 机制 纳米级执行计划

## 1. 目标与影响范围
- **目标**: 记录关键操作（POST/PUT/DELETE），保存“谁、什么时间、对什么资源、做了什么”的信息，并支持界面展示，自动清理 90 天前数据。
- **影响范围**:
  - `internal/domain/audit.go` (New)
  - `internal/infrastructure/persistence/sqlite.go` (Schema update)
  - `internal/infrastructure/persistence/audit_repository.go` (New)
  - `internal/application/audit_service.go` (New)
  - `internal/interfaces/api/middleware.go` (Add AuditMiddleware)
  - `internal/interfaces/api/audit_handler.go` (New)
  - `internal/interfaces/api/router.go` (Inject AuditMiddleware)
  - `web/src/api/index.ts`
  - `web/src/views/AuditLog.vue` (New)
  - `web/src/router/index.ts`, `web/src/views/Layout.vue`

## 2. 详细步骤 (Red-Green Refactor)

### 2.1 [RED 阶段] 编写测试
1. 创建 `internal/domain/audit_test.go` (定义结构)。
2. 创建 `internal/infrastructure/persistence/audit_repository_test.go`，测试 `Create` 和 `List` 方法。
3. 创建 `internal/application/audit_service_test.go`，测试日志记录及 `Prune` (清理 90 天前) 功能。
4. 创建 `internal/interfaces/api/audit_handler_test.go`，测试 `GET /api/audit-logs` 接口。
5. 前端在 `web/src/views/AuditLog.spec.ts` 编写组件渲染测试。

### 2.2 [GREEN 阶段] Domain & Persistence (后端基础设施)
1. **`internal/domain/audit.go`**:
   - 定义 `AuditLog` 结构体：`ID, UserID, Username, Method, Path, Details, CreatedAt`。
   - 定义 `AuditRepository` 接口。
2. **`internal/infrastructure/persistence/sqlite.go`**:
   - 在 `InitDB` 中新增 `CREATE TABLE IF NOT EXISTS audit_logs ...`。
3. **`internal/infrastructure/persistence/audit_repository.go`**:
   - 实现 `Create`, `List`, `DeleteOlderThan` 方法。

### 2.3 [GREEN 阶段] Application & API (后端业务与中间件)
1. **`internal/application/audit_service.go`**:
   - 实现 `RecordAction` 和 `GetLogs`。提供一个独立的 Goroutine 异步定期执行 `PruneLogs`（如每 24 小时一次，或者每次写入时概率触发，以保持简单）。
2. **`internal/interfaces/api/middleware.go`**:
   - 新增 `AuditMiddleware(auditSvc AuditService)`: 拦截所有 `POST/PUT/DELETE` 请求，在请求完成后将 `Method`, `Path`, `UserID`, `Username` 异步写入审计日志。
3. **`internal/interfaces/api/audit_handler.go`**:
   - 实现 `GetAuditLogs` 接口 (限制仅 Admin 可访问，或根据 RBAC 需求设计)。
4. **`internal/interfaces/api/router.go`**:
   - 将 `AuditMiddleware` 注册到需要鉴权的路由组。注册 `GET /api/audit-logs`。

### 2.4 [GREEN 阶段] Frontend (前端集成)
1. **`web/src/api/index.ts`**:
   - 增加 `getAuditLogs()` API 调用。
2. **`web/src/views/AuditLog.vue`**:
   - 使用 Element Plus `el-table` 渲染日志列表（时间倒序）。
3. **`web/src/router/index.ts` & `web/src/views/Layout.vue`**:
   - 增加 `审计日志` 导航菜单项 (仅 Admin 可见)。
